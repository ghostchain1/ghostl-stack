# Regulator Mode Views

Required views:
- Constitutional status (clause summary and amendment log)
- Supply and burn ledger (L1/L2/L3 reconciliation)
- Governance proposals and votes
- Sequencer revenue and slashing
- ZK proof verification panel
- Evidence pack downloads

Notes:
All views are read-only and derived from deterministic data sources.
Portal route: `/compliance/transparency`
Live compliance endpoints: `/v1/policies`, `/v1/policies/active`, `/v1/laws`, `/v1/predictions`
Protected audit data (decisions/evidence) remains analyst/admin-gated.
