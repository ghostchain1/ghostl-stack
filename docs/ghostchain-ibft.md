# GhostChain IBFT (local Besu network)

GhostChain is the main Autonomous Layer 1 blockchain in this stack. This guide sets up a standalone GhostChain L1 using IBFT (Besu) with 4 validators, autogenerated keys, adjustable gas limit, and a unique dev/testnet chainId.

## Files
- `infra/ghostchain/ibft/config.yaml` – template (chainId, block time, gas limit, premine).
- `infra/ghostchain/ibft/generate.sh` – generates genesis + validator keys via Besu operator.
- `infra/ghostchain/docker-compose.ibft.yml` – runs 4 Besu validators; node1 exposes RPC/WS/metrics.

## Generate the network
```bash
cd infra/ghostchain/ibft
# optional overrides: CHAIN_ID, BLOCK_PERIOD, EPOCH_LENGTH, GAS_LIMIT_HEX
bash generate.sh
```
Outputs to `infra/ghostchain/ibft/networkFiles/` (genesis.json, peers.txt, keys/node{1..4}/key).

## Run the validators
```bash
cd infra/ghostchain
docker compose -f docker-compose.ibft.yml up -d
```

RPC/WS (node1):
- HTTP: http://localhost:18545
- WS: ws://localhost:18546
- Metrics: http://localhost:18660
- ChainId: from config (default 14000101)

## Adjustments
- Change chainId/block period/gas limit in `generate.sh` or edit `config.generated.yaml` before running Besu operator.
- Premine addresses are in `generate.sh` (prefunded dev keys); edit as needed.
- To rebuild from scratch: remove `infra/ghostchain/ibft/networkFiles` and rerun `generate.sh`.
