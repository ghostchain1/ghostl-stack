## 9. UI & Dashboard Design Principles

### Design Language

- **Dark mode primary.** No light-mode-first design.
- **Glass morphism (controlled).** Subtle backdrop blur on panels only.
- **Neon edge highlights.** Border glows on active/hover states only.
- **High contrast metrics.** KPI values must be immediately readable.
- **AI command center feel.** Dense information, clean hierarchy.
- **Grid-based layout.** No freeform positioning.

### Component Principles

- Cards: `rgba(11,15,20,0.85)` background, `1px solid rgba(122,92,255,0.15)` border
- Active states: layer-specific accent glow
- Hover: `translateY(-2px)` + subtle border brightening
- Animations: `rise` (fade up), `pulse` (status indicators) — no bounce, no spin
