# ghostload-sim

Offline simulator/replay tool for GhostLoad policy and control behavior.

## Usage
- `node src/cli.js --scenario=l1-fee-spike`
- `node src/cli.js --scenario=spam-attack --out=reports/spam.json`

## Included stress scenarios
- l1-fee-spike
- l2-sequencer-slowdown
- l3-demand-surge
- spam-attack
- bridge-burst
