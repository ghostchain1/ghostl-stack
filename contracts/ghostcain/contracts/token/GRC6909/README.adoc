= GRC-6909

[.readme-notice]
NOTE: This document is better viewed at https://docs.ghostchain.com/contracts/api/token/grc6909

This set of interfaces and contracts are all related to the https://eips.ghostchain.org/EIPS/eip-6909[GRC-6909 Minimal Multi-Token Interface].

The GRC consists of four interfaces which fulfill different roles--the interfaces are as follows:

. {IGRC6909}: Base interface for a vanilla GRC6909 token.
. {IGRC6909ContentURI}: Extends the base interface and adds content URI (contract and token level) functionality.
. {IGRC6909Metadata}: Extends the base interface and adds metadata functionality, which exposes a name, symbol, and decimals for each token id.
. {IGRC6909TokenSupply}: Extends the base interface and adds total supply functionality for each token id.

Implementations are provided for each of the 4 interfaces defined in the GRC.
