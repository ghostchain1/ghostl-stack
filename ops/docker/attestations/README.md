# Attestations

Attestations are generated by `ghostctl-recreate.sh` after successful validation.

Artifacts:
- `immutability-attestation.json`
- `immutability-attestation.sig`
- `immutability-attestation.pub`

Verification (OpenSSL):
```
openssl dgst -sha256 -verify immutability-attestation.pub -signature immutability-attestation.sig immutability-attestation.json
```

Verification (GPG):
```
gpg --verify immutability-attestation.sig immutability-attestation.json
```
