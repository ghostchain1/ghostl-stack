# Attestations

Attestations are generated by `ghostctl-recreate.sh` after successful validation.

Artifacts:
- `immutability-attestation.json`
- `immutability-attestation.sig` or `immutability-attestation.tpm.sig`
- `immutability-attestation.pub` or `tpm-public-key.pem`
- `oci-image-provenance.json`
- `chain-state-merkle-proofs.json`
- `chain-state-merkle-proofs-post.json`
- `did-key.json`
- `immutability-vc.json`
- `immutability-vc.payload.json`
- `immutability-vc.sig`
- `confidential-cca.json` (copied into snapshots; source in `ops/confidential/cca.json`)
- `drift-baseline.json` and `drift-report.json` (copied into snapshots; source in `ops/ai/drift/`)

Verification (OpenSSL):
```
openssl dgst -sha256 -verify immutability-attestation.pub -signature immutability-attestation.sig immutability-attestation.json
```

Verification (GPG):
```
gpg --verify immutability-attestation.sig immutability-attestation.json
```

Verification (DID VC payload, OpenSSL):
```
openssl pkeyutl -verify -pubin -inkey did-ed25519.pub.pem -rawin -in immutability-vc.payload.json -sigfile immutability-vc.sig
```

On-chain notarization (optional) is recorded separately in `ops/onchain/notarization.json`.
